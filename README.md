# Volumes spike, run 2

A throwaway sandbox for testing whether Claude Code Projects can run and drive the
Volumes Android port pipeline. Nothing here ships.

- `RUNBOOK.md`: the numbered checklist. Start there.
- `RESULTS.md`: the results sheet.
- `project/instructions.txt`: paste into the project's instructions once.
- `.claude/`: the skills (`s2-*`), the probe agent, the probe workflow and the
  settings probes that the tests use.
- `toy/`: a tiny function and its tests, so CI has something real to fail.
